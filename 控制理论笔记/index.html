连续系统建模与分析#

建模#

  • 电路：
    • 直接用阻抗导纳形式建模，不要用时域方程，因为很多时候都是微分方程，写不出来。
    • 用回路电压法，得到关于电流的方程
  • 平动：
    • 用每个元件的位移为基础，建立力的关系（上侧位移、下侧位移差即为位移）。
    • 如果有质量块，对质量块分析牛二，其余的都是合力为0
  • 转动：
    • 类似平动，以角位移为基础

相似系统的微分方程不见得完全一致，特征方程肯定是一致的。下面每组中的变量，建立微分方程是一致的

  • 电流方程 - 速度方程 - 角速度方程，都是一阶导+一阶积分

因此，如果使用电流阻抗\(U(s)/I(s)\)，机械阻抗\(F(s)/V(s)\)，可以统一如下。但建议不要过分追求阻抗表达式的形式相似，而是关注微分方程的整体形式

传递函数#

开环传递函数​ 的定义是：在反馈回路断开的情况下，从施加在控制器/被控对象 G(s)输入端的信号，到反馈点（比较点之前） 的信号之间的传递函数

  • \(G\)，前向通道传递函数
  • \(GH\)，开环传递函数
  • \(\dfrac{G}{1+GH}\)，闭环传递函数

也有人定义，反馈信号与误差信号之比为开环，也是\(GH\)，但是感觉不太直观……

\[周期函数：F(s) = \mathcal{L}\{f(t)\} = \sum_{n=0}^{\infty} \mathcal{L}\{f_1(t - nT)=\sum_{n=0}^{\infty} e^{-nTs}F_{1}(s)=F_{1}(s)\sum_{n=0}^{\infty}\left(e^{-s T}\right)^{n}\}\]

推导：

设 \(F(s)=\mathcal L\{f(t)\}\)，单边拉普拉斯变换为

\[F(s)=\int_0^{\infty}e^{-st}f(t)\,dt.\]

分部积分给出

\[\mathcal L\{f^{(n)}(t)\} =s\mathcal L\{f^{(n-1)}(t)\}-f^{(n-1)}(0^+) =s^nF(s)-\sum_{k=1}^{n}s^{n-k}f^{(k-1)}(0^+).\]

对 \(a\geq0\)，时间平移与复频域平移分别满足

\[\begin{aligned} \mathcal L\{f(t-a)u(t-a)\}&=e^{-as}F(s),\\ \mathcal L\{f(t+a)\}&=e^{as}\left[F(s)-\int_0^a e^{-st}f(t)\,dt\right],\\ \mathcal L\{e^{at}f(t)\}&=F(s-a). \end{aligned}\]

时间提前时须保留被移出积分区间的部分；不能一般地写成 \(e^{as}F(s)\)。

终值：\(F(s)\)的所有极点都必须位于 s 平面的左半平面（LHP）或在原点处至多有一个一阶极点。

连续系统时域#

劳斯判据#

必要性：当其传递函数特征方程（分母等于零的方程）的最高次项系数化为正数后，所有系数都必须为正

设 \(a_n>0\)，劳斯表前两行为

\[\begin{array}{c|ccc}s^n&a_n&a_{n-2}&\cdots\\s^{n-1}&a_{n-1}&a_{n-3}&\cdots\end{array}\]

后续各行由相邻两行递推。例如 \(s^{n-2}\) 行的首项为 \(b_1=(a_{n-1}a_{n-2}-a_na_{n-3})/a_{n-1}\)；其余项按同样规则计算。

  • 遇到第一列是0
    • 改写方程为\(s=1/t\)，重新计算
    • 假设为非常小的正数\(\epsilon\)
  • 遇到全0行
    • 上一行方程，求导得到这一行的系数
    • 上一行方程的纯虚根\(\pm j\omega\)对应震荡频率\(\omega\)
    • 可出现在s的奇数或偶数次方行

全零行意味着存在关于原点对称的根

劳斯表很大的时候可以缩放，但是只能使用正数进行缩放（乘以或除以一个正数）

二阶系统#

闭环：

\[G(s) = \frac{\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2}\]
\[s_{1,2} = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2-1}\]

开环：

\[G(s) = \frac{\omega_n^2}{s(s+2\zeta\omega_n)}\]

研究的是欠阻尼情况的暂态响应，临界阻尼和过阻尼都没有超调。临界阻尼是无超调最快上升系统

研究的是阶跃响应 系统的震荡周期是\(\dfrac{2\pi}{w_d}\)，包络线是\(e^{-\zeta\omega_nt}\)，

\[g(t) = 1-\frac{1}{\sqrt{1-\zeta^2}}e^{-\zeta\omega_nt}\sin(\omega_d t+\arccos \zeta)\]

记住：\(\beta=\arccos \zeta = \arctan \dfrac{\sqrt{1-\zeta^{2}}}{\zeta}\)

标准欠阻尼二阶系统（\(0<\zeta<1\)），令 \(\beta=\arccos\zeta\)：

\[\begin{aligned} \omega_d&=\omega_n\sqrt{1-\zeta^2},& t_p&=\frac{\pi}{\omega_d},\\ M_p&=\exp\left(-\frac{\zeta\pi}{\sqrt{1-\zeta^2}}\right),& t_r&=\frac{\pi-\beta}{\omega_d},\\ t_s(2\%)&\approx\frac{4}{\zeta\omega_n},& t_s(5\%)&\approx\frac{3}{\zeta\omega_n}. \end{aligned}\]

这里 \(t_r\) 指首次由零上升到稳态值的时间；百分比超调量为 \(100M_p\%\)。

根轨迹#

写出首一标准型

\[G_k(s) = K_g \frac{\prod_{i=1}^m (s - z_i)}{\prod_{j=1}^n (s - p_j)}\]

（负反馈下）特征方程：\(1+GH=0\)，其中\(GH\)是首一标准型，一定要是首一，这样才能确定绘制的是0度还是180度根轨迹。

核心是确定\(\dfrac{\prod_{i=1}^m (s - z_i)}{\prod_{j=1}^n (s - p_j)}\)的相角是180度还是0度！

\(s-p_{j}\)是从\(p_{j}\)指向\(s\)的向量！

180度基本规则#
  • 求开环极点n个、零点m个
  • 则有\(\max{(m,n)}\)条根轨迹
  • 始于开环几点，终于开环零点或无穷远
  • 确定实轴上的根轨迹
  • 确定渐近线的交点、方向
  • 如果是复数极点，要求出射角
  • 如果有分离，要求分离点，当\(m\ne n\)时，分离点/汇合点方程是一个 (m+n-1) 阶的方程
  • 如果有虚轴交点，要求出来

  1. 实轴上的根轨迹：实轴上某线段右侧开环零、极点数目之和为奇数时，该线段为根轨迹（因为是180度）

  2. 渐近线：

    • 渐近线方向角：

      \[\theta_k = \frac{(2k+1)\pi}{n-m}, \quad k=0,1,\dots,|n-m|-1\]

    • 渐近线交点：

      \[\sigma_a = \frac{\sum p_j - \sum z_i}{n-m}\]

  3. 分离点与会合点：

    • 满足方程：

      \[\sum \frac{1}{d - p_j} = \sum \frac{1}{d - z_i}\]

    • 或解\(\frac{dK_g}{ds}=0\)

    • 分离角：有n条汇入，就有n条汇出，则每条的夹角为\(\dfrac{(2k)\pi}{2n}\)，且为一进一出交替。这么看射出的夹角则是\(\dfrac{(2k)\pi}{n}\)

  4. 出射角与入射角：

    • 出射角（从开环极点\(p_l\)）：

      \[\theta_{p_l} = (2k+1)\pi + \left( \sum \angle(p_l - z_i) - \sum_{j \neq l} \angle(p_l - p_j) \right)\]

    • 入射角（至开环零点\(z_l\)）：

      \[\theta_{z_l} = (2k+1)\pi - \left( \sum_{i \neq l} \angle(z_l - z_i) - \sum \angle(z_l - p_j) \right)\]

  5. 虚轴交点：令\(s=j\omega\)代入特征方程，解实部、虚部方程

设开环传递函数为

\[K\frac{\prod_i(s-z_i)}{\prod_j(s-p_j)},\qquad K>0.\]

特征方程给出角度条件

\[\sum_i\arg(s-z_i)-\sum_j\arg(s-p_j)=(2k+1)\pi.\]

其中 \(s-p_j\) 的方向是从极点 \(p_j\) 指向 \(s\)。实轴上一点右侧的实零点与实极点个数之和为奇数时，该点属于正增益根轨迹。

对简单极点 \(p_m\)，出射角为

\[\theta_{\mathrm d}=(2k+1)\pi+\sum_i\arg(p_m-z_i) -\sum_{j\ne m}\arg(p_m-p_j).\]

对简单零点 \(z_n\)，入射角（以 \(s-z_n\) 的方向定义）为

\[\theta_{\mathrm a}=-(2k+1)\pi-\sum_{i\ne n}\arg(z_n-z_i) +\sum_j\arg(z_n-p_j).\]

角度均按 \(2\pi\) 等价取值；多重零、极点须相应考虑其重数。

其他#

0度根轨迹就是相角条件变成\(2k \pi\)，别的都不变。 绘制规则变化：

  • 实轴上的根轨迹：右侧开环零、极点数目之和为偶数

  • 渐近线方向角：

    \[\theta_k = \frac{2k\pi}{n-m}, \quad k=0,1,\dots,|n-m|-1\]

  • 出射角/入射角公式中的\((2k+1)\pi\)改为\(2k\pi\)

广义根轨迹就是 将特征方程整理为：

\[1 + K \frac{P(s)}{Q(s)} = 0\]

其中\(K\)为可变参数，则等效开环传递函数为\(G^*(s) = \frac{P(s)}{Q(s)}\)

增加一个开环零点会使根轨迹向零点方向弯曲。零点吸引根轨迹的分支；增加左侧零点可以改善稳定性和速度，但可能增加超调 极点排斥根轨迹，使根轨迹向右半平面移动，降低稳定性；使系统响应变慢，增加阻尼，减少超调量，但延长调节时间

根轨迹与幅值裕度#

当开环零、极点保持不变，仅改变正增益 \(K\) 时，根轨迹的虚轴交点满足

\[K_{\mathrm{cr}}\frac{\prod_i(j\omega_g-z_i)}{\prod_j(j\omega_g-p_j)}=-1.\]

虚轴交点的频率由角度条件确定。对当前增益 \(K_0\)，若 \(K_{\mathrm{cr}}\) 是增益增大时首次失稳的临界增益，则幅值裕度为

\[K_g=\frac{K_{\mathrm{cr}}}{K_0},\qquad K_g\,\left|K_0\frac{\prod_i(j\omega_g-z_i)}{\prod_j(j\omega_g-p_j)}\right|=1.\]

根轨迹与虚轴的交点，即为\(G(jw)=-1\)的点，因而其其实反应了没有K的系统的幅值裕度，不难得到\(G^{'}(jw)= \dfrac{G(jw)}{K}=-\dfrac{1}{K}\)

三种绘制方法#

解析法：求出\(x\) 与 \(\dot{x}\) 的关系，就可以直接画图 等倾斜线法：

  1. 相轨迹的斜率是\(\dfrac{d\dot{x}}{dx}\)，也就是\(\dfrac{\ddot{x}}{\dot{x}}\)
  2. 令斜率为\(\alpha\)，也即\(\ddot{x}=\alpha \dot{x}\)，代入原方程，求解出\(\dot{x}\)与\(x\)的关系——等倾斜线方程
  3. 给定\(\alpha\)，该方程对应一条曲线，在曲线上画出斜率为\(\alpha\)的线段，这就是相轨迹的一部分
  4. 用这样的一系列线段拼接出相轨迹

\(\delta\)法：原圆弧来拼接

  1. 令\(-f(x,\dot{x})+w^{2}x=\delta\)，其中\(w\)是给定值，\(\ddot{x}+f=0\)
  2. 则有\(\ddot{x}+w^{2}x=\delta\)，这是一个简谐振动的方程
  3. 实际做图步骤
    1. 选择点P
    2. 求点P对应的\(\delta\)值：\(-f(x,\dot{x})+w^{2}x=\delta\)
    3. 以\((\delta/w^{2},0)\)为圆心，过P做一段圆弧
    4. 在圆弧上找到新的点\(P^{'}\)，重复此步骤

能观能控#

这里给出的都是完全能控判据，若不完全能控，不代表完全不能控。能控\(r(Q_c)\)个的变量的线性组合

能控性#

能控性矩阵

\[Q_{c}=[B \ AB \ A^2B \ \cdots \ A^{n-1}B]\]

PBH判据：

\[\text{rank}[A-\lambda I \ B] = n, \quad \forall \lambda \in \mathbb{C}\]

对角线规范型判据：

  • \(A\)对角化后，如果没有重特征值，则\(B\)无全零行 \(\iff\) 系统完全能控
  • 全0行对应的模态不能控

输出能控性，不关心系统内部的所有状态是否都被控制，只关心这些状态和输入的组合能否影响到每一个输出分量：

\[Q_{h}=[CB \ CAB \ CA^2B \ \cdots \ CA^{n-1}B \ D]=[C*Q_{c}, D]\]

判据要求这个“所有可能控制路径”的集合（矩阵）是行满秩的，其行数等于输出维数 p。

能观性#

能观性矩阵

\[Q_{o}=\begin{bmatrix} C \\ CA \\ CA^2 \\ \vdots \\ CA^{n-1} \end{bmatrix}\]

PBH判据

\[\text{rank}\begin{bmatrix} A-\lambda I \\ C \end{bmatrix} = n, \quad \forall \lambda \in \mathbb{C}\]

对角线规范型判据：

  • \(A\)对角化后，如果没有重特征值，则\(C\)无全零列 \(\iff\) 系统完全能观
单个变量的能观能控性#

化为约当标准型

  • 不同约当块对应不同特征值时，首先判断约当块是否能控能观
    • 约当块对应的\(B\)的最后一行不全为\(0\)，能控
    • 约当块对应的\(C\)的第一列不全为\(0\)，能关
  • 在无重特征值的对角型下，如果块不能控能观，再看块内部各变量
    • 对\(x_i\)，\(B\)的第\(i\)行不全为\(0\)，能控；
    • \(C\)的第\(i\)列不全为\(0\)，能观
传递函数的实现与标准型#

根据卡尔曼分解定理，一个系统可以被分解成四个部分。

  • 传递函数仅仅描述了一个系统“既能控又能观”的那一部分子动力学，也就是只看到\(C(sI-A)^{-1}B\)
  • 完全能控能观等价条件：\(G(s\))是既约的，即无零极点对消
  • 不对消的极点是传递函数的一部分，在任何实现中都必须既是能控的又是能观的
  • 对消的极点的能观能控性，受实现方式的影响
  • 由传递函数构造状态空间，可以选择不同的状态变量，会影响各模态的能观性和能控性

因而不同的实现（传递函数的存在已经保证了至少能控或至少能观/可以化为标准型）

  • 如果系统完全能观能控，各标准型都完全能观能控
  • 否则
    • 能控标准型：优先保证系统是完全能控的（哪怕是对消极点对应的模态），这导致了状态变量是耦合的，我们无法观测单个变量，不能简单地说"x₁能观，x₂不能观，可以观测的是能观维度的变量组合
    • 能观标准型：优先保证系统的能观的，同上
    • 对角标准型：每个状态变量（模态）对应一个极点
      • 对角型的优势在于各部分解耦，容易观察
      • 输入矩阵 \(B\)中是否有全零行。如果有，那么该行对应的模态（极点）是不能控的
      • 输出矩阵 \(C\)中是否有全零列。如果有，那么该列对应的模态（极点）是不能观的
  • 最小实现：传递函数的一个状态空间实现是最小实现\(\iff\)它既完全能控又完全能观。最小实现的维数等于传递函数的分母次数（假设传递函数是既约的)

线性变换#

\[\underset{\text{原系统}}{(A, B, C, D)} \quad \overset{\mathbf{x} = T\mathbf{z}}{\xrightarrow{\hspace{2cm}}} \quad \underset{\text{新系统}}{(T^{-1}AT,\; T^{-1}B,\; CT,\; D)}\]

作常数可逆变换 \(x=Tz\)，则

\[T\dot z=ATz+Bu,\qquad y=CTz+Du,\]

即

\[\dot z=T^{-1}ATz+T^{-1}Bu,\qquad y=CTz+Du.\]

由于

\[sI-T^{-1}AT=T^{-1}(sI-A)T,\]

有

\[\begin{aligned} CT(sI-T^{-1}AT)^{-1}T^{-1}B &=CT\left[T^{-1}(sI-A)T\right]^{-1}T^{-1}B\\ &=C(sI-A)^{-1}B. \end{aligned}\]

因此，相似变换不改变传递函数。

化为能控能观#

性变换不改变系统的特征多项式，这里的L直接使用原系统的特征多项式构造即可

\[L= \begin{bmatrix} \alpha_1 & \alpha_2 & \cdots & \alpha_{n-1} & 1 \\ \alpha_2 & \alpha_3 & \cdots & 1 & 0 \\ \vdots & \vdots & \ddots & \vdots & \vdots \\ \alpha_{n-1} & 1 & \cdots & 0 & 0 \\ 1 & 0 & \cdots & 0 & 0 \\ \end{bmatrix}\]
\[\begin{align} T_{c}&=Q_{c}*L\\ T_{o}^{-1}&=L*Q_{o} \end{align}\]

在 \(x=T_cz\) 下，能控性矩阵满足

\[\overline Q_c=[\,T_c^{-1}B\ \ T_c^{-1}AB\ \cdots\ \ T_c^{-1}A^{n-1}B\,] =T_c^{-1}Q_c.\]

对上述标准型，\(\overline Q_c=L^{-1}\)，所以

\[T_c=Q_c\overline Q_c^{-1}=Q_cL.\]

同理，\(x=T_oz\) 时 \(\overline Q_o=Q_oT_o\)。对相应的能观标准型，\(\overline Q_o=L^{-1}\)，从而

\[T_o^{-1}=\overline Q_o^{-1}Q_o=LQ_o.\]

特征分解#

不能控但非完全不能控的(A,B,C,D) 可以分解为一个p维的能控子系统和一个n-p维的完全不能控子系统，这种分解便称为是能控性分解。

能控分解变换矩阵求解：

  1. 求出\(r=\text{rank}[B \ AB \ \cdots \ A^{n-1}B]\)
  2. 取\(T_1=[b_1 \ Ab_1 \ \cdots \ A^{r-1}b_1 \ \cdots]\)（线性无关列）
  3. 补\(T_2\)使\(T=[T_1 \ T_2]\)满秩

  • 分解形式：

    \[\begin{bmatrix} \dot{\bar{x}}_c \\ \dot{\bar{x}}_{uc} \end{bmatrix} = \begin{bmatrix} \mathbf{A}_{c} & \mathbf{A}_{12} \\ \mathbf{0} & \mathbf{A}_{uc} \end{bmatrix} \begin{bmatrix} \bar{x}_c \\ \bar{x}_{uc} \end{bmatrix}+\begin{bmatrix} \mathbf{B}_c \\ \mathbf{0} \end{bmatrix} u\]
\[y = \bar{C}\bar{x} = \begin{bmatrix} \mathbf{C}_c & \mathbf{C}_{uc} \end{bmatrix} \begin{bmatrix} \bar{x}_c \\ \bar{x}_{uc} \end{bmatrix} \]

能观分解变换矩阵求解：

  1. 选取\(r=\text{rank}Q_{o}\)
  2. 取\(T_1\)为\(Q_o\)中r个线性无关的行向量
  3. 补\(T_2\)使\(T=[T_1 ; T_2]\)满秩，则此为变换矩阵的逆矩阵

  • 分解形式：

    \[\begin{bmatrix} \dot{\tilde{x}}_o \\ \dot{\tilde{x}}_{uo} \end{bmatrix} = \begin{bmatrix} \mathbf{A}_{o} & \mathbf{0} \\ \mathbf{A}_{21} & \mathbf{A}_{uo} \end{bmatrix} \begin{bmatrix} \tilde{x}_o \\ \tilde{x}_{uo} \end{bmatrix}+\begin{bmatrix} \mathbf{B}_o \\ \mathbf{B}_{uo} \end{bmatrix} u\]
\[y = \tilde{C} \tilde{x} = \begin{bmatrix} \mathbf{C}_o & \mathbf{0} \end{bmatrix} \begin{bmatrix} \tilde{x}_o \\ \tilde{x}_{uo} \end{bmatrix}\]
\[x = T_o \tilde{x} = \begin{bmatrix} T_{o1} & T_{o2} \end{bmatrix} \begin{bmatrix} \tilde{x}_o \\ \tilde{x}_{uo} \end{bmatrix}\]

状态反馈与输出反馈#

反馈都是反馈到输入\(u\)，状态反馈即将状态值反馈到输入

\[\begin{align*} u(t) &= r(t) - Kx(t) \\ \dot{x}\,(t) &= (A - BK)x(t) + Br(t) \\ y(t) &= (C - DK)x(t) + Dr(t) \end{align*}\]

\(K\) 为一行向量

输出反馈则为\(u=v-Hy=(I+HD)^{-1}(v-HCx),\quad\det(I+HD)\ne0\)，相当于经典控制里的反馈，不能自由配置极点，只能用直接法

\[\begin{align*} u(t) &= r(t) - Hy(t) \\ \dot{x}\,(t) &= [A-B(I+HD)^{-1}HC]x(t)+B(I+HD)^{-1}r(t) \\ y(t) &= Cx(t) + Du(t) \end{align*}\]
直接法#

目标特征多项式：\(\Delta^{*}(s)\) 反馈后多项式：\(|sI-(A - BK)|=\Delta(s)\) 令各阶次系数相等，即可解出\(K\)的各项

能控标准型法#

目标特征多项式：\(\Delta^{*}(s)\) 原系统多项式：\(|sI-A|=\Delta(s)\) 在能控标准型下的反馈矩阵\(K_{c}=(a^{*}_{0}-a_{0}, a^{*}_{1}-a_{1}, \cdot , a^{*}_{n-1}-a_{n-1})\) 求逆变换：\(K_{c}=K \times T_{c} \implies K=K_{c} T_{c}^{-1}\)

全维观测器#

将观测器的输出与实际输出作差，反馈到微分

\[\begin{align} \dot{\hat{x}}(t) &= A\hat{x}(t) + Bu(t) + H[y(t) - \hat{y}(t)] \\ \hat{y}(t) &= C\hat{x}(t) + Du(t) \end{align}\]

则

\[\dot{\hat{x}}(t) = (A - HC)\hat{x}(t) + (B - HD)u(t) + Hy(t)\]

\(H\)为一列向量， 不需要记忆这个式子，记住第一个，也即\(\dot{\hat{x}}(t) = A\hat{x}(t) + Bu(t) + Hy(t) - H\hat{y}(t)\)

直接法#

目标特征多项式：\(\Delta^{*}(s)\) 反馈后多项式：\(|sI-(A - HC)|=\Delta(s)\) 令各阶次系数相等，即可解出\(K\)的各项

能控标准型法#

目标特征多项式：\(\Delta^{*}(s)\) 原系统多项式：\(|sI-A|=\Delta(s)\) 在能观标准型下的反馈矩阵\(H_{o}=(a^{*}_{0}-a_{0}, a^{*}_{1}-a_{1}, \cdot , a^{*}_{n-1}-a_{n-1})^{T}\) 求逆变换：\(H_{o}=T_{o}^{-1} \times H \implies H=T_{0} \times H_o\)

降维观测器#

若\(r=\text{rank}C\)，则\(y\)可以由\(r\)个状态表示，可以构造变换矩阵 \(Q\) 将系统分解为输出相关和无关部分

分解系统：

  1. 计算\(r=\text{rank}C\)，则观测器维数为\(n-r\)

  2. 取\(C\)中r个线性无关的行向量\(C_{r}\)

  3. 补\(R\)使\(Q^{-1}=[C_r ; R]\)满秩，则此为变换矩阵的逆矩阵

  4. 做变换\(x=Qz\)，记前\(r\)个可直接观测的状态为\(y\)

    \[\begin{bmatrix} \dot{y} \\ \dot{z_{2}} \end{bmatrix} = \begin{bmatrix} \mathbf{A}_{11} & \mathbf{A}_{12} \\ \mathbf{A}_{21} & \mathbf{A}_{22} \end{bmatrix} \begin{bmatrix} y\\ z_{2} \end{bmatrix}+\begin{bmatrix} \mathbf{B}_1 \\ \mathbf{B}_2 \end{bmatrix} u\]

  5. 展开为关于状态\(z_2\)的\(n-r\)阶降阶系统

    \[\begin{align} \dot{z}_{2} &=A_{22}z_{2}+(B_{2}u+A_{21}y)\\ \dot{y}-A_{11}y -B_{1}u &=A_{12}z_{2} \end{align}\]

  6. 也即

    \[\begin{align} \dot{z}_{2} &=A_{22}z_{2}+v\\ w &=A_{12}z_{2} \end{align}\]

对子系统\(\dot{z}_{2}=A_{22}z_{2}+(B_{2}u+A_{21}y)\)设计全维观测器

  • 观测器矩阵\(H\)

    \[\begin{align} \dot{\hat{z}}_{2} &=(A_{22}-HA_{12})\hat{z}_{2}+v+Hw\\ w &=\dot{y}-A_{11}y-B_1u \end{align}\]

  • 根据要求的极点，计算\(H\)的值即可完成观测器设计

写出观测器完整形式

  • 为了消除\(\dot{y}\)，引入变量替换（容易推导，展开\(w\)，其中有一项\(H\dot{y}\)）

    \[r=\hat{z}_{2}-Hy\]

  • 得到

    \[\begin{align} \dot{r} &=(A_{22}-HA_{12})r+[(A_{22}-HA_{12})H+A_{21}-HA_{11}]y+(B_2-HB_1)u\\ w &=\dot{y}-A_{11}y-B_1u \end{align}\]

  • 观测器

    \[\hat{x}=Q\hat{z}=Q\begin{bmatrix} y \\ r+Hy \end{bmatrix}\]

其中\(r\)根据微分方程可以快速计算

镇定问题#

状态反馈镇定#

充要条件：不能控部分渐进稳定（负实部极点）

判别

  • 做能控子空间分解，并求不能控系统的极点（这一步几乎是必须的，因为我们无法直接从系统的特征值得出那部分对应能控，哪部分不能控）
  • 不能控系统包括：能观不能控部分、既不能控又不能观部分，在能控子空间分解里，这部分没有解耦出来

设计方法一

  • 对能控部分设计状态反馈阵
  • 逆变换，得到原系统的状态反馈阵

设计方法二

  • 直接对原系统设计反馈阵，在设计过程中，自然会发现不能控部分极点不变（因式不受反馈阵影响）
  • 这样求得的关于K的方程有无穷多解，取一个即可

理论上，特征值互异的矩阵，对角化后可以直接根据全0行判别不能控模态（同时也得到极点）。但是能控性分解方法适用于所有线性系统，无论是否可对角化，所以还是能控性方法好，计算量也更小

输出反馈镇定#

充要条件：

  • 能控不能观部分、能观不能控部分、既不能控又不能观部分，渐进稳定；
  • 能控且能观部分，输出反馈能配置出负实部极点

输出 y不能反映不能观子系统，只能控制能控能观部分，所以我们需要更精细的分解

判别

  • 做卡尔曼分解，求三个部分的极点
  • 对能控能观部分设计输出反馈，看是否存在可行的控制器
  • 做逆变换

MIMO解耦控制问题#

解耦控制概述#

对MIMO系统，其具备传递函数矩阵

\[\begin{bmatrix} y_1(s) \\ y_2(s) \\ \vdots \\ y_q(s) \end{bmatrix} = \begin{bmatrix} g_{11}(s) & g_{12}(s) & \cdots & g_{1p}(s) \\ g_{21}(s) & g_{22}(s) & \cdots & g_{2p}(s) \\ \vdots & \vdots & \ddots & \vdots \\ g_{q1}(s) & g_{q2}(s) & \cdots & g_{qp}(s) \end{bmatrix} \begin{bmatrix} u_1(s) \\ u_2(s) \\ \vdots \\ u_p(s) \end{bmatrix}\]

解耦控制即：寻找合适的\(u\)，使得传递函数矩阵变成对角阵，实现一个输入对应一个输出

必要条件：

  • \(p=q\)，输入向量与输出向量维度一致
  • 解耦后对角线上无零元素
串联补偿解耦（频域）#

这是经典控制的方法，单位负反馈，串联一个补偿器\(G_{c}(s)\)，

给定对角形式的闭环传递函数：

\[\Phi(s) = [I + G_0(s) G_c(s)]^{-1} G_0(s) G_c(s)\]

由于\(\Phi(s)\)是对角阵，故\(G_{0}G_{c}\)是一个对角阵

解得：

\[G_c(s) = G_0^{-1}(s) \Phi(s) [I - \Phi(s)]^{-1}\]

很多时候，是给定开环对角阵\(G_{0}G_{c}\)。

传递函数矩阵的乘法：数学上，函数复合\(f(g(x))\)就是先g后f，写作\(f o g\)，先作用的函数写在右边，后作用的函数写在左边 而框图从左到右的物理布局刚好对应这个从内到外的函数嵌套顺序。矩阵乘法不可交换性则决定了这个顺序绝对不能调换。

后作用的函数写在左边

状态反馈动态解耦（时域）#

状态反馈+输入变换阵\(L\)：

\[\begin{align} \mu&=-Kx+Lv\\ \dot{x}&=(A-BK)x+BLv\\ y&=Cx \end{align}\]

寻找合适的\((K,L)\)，使得

\[G_{KL}(s) = C(sI - A + BK)^{-1}BL = \begin{bmatrix} g_{11}'(s) & \cdots \\ \vdots & g_{pp}'(s) \end{bmatrix}\]

限制条件

  • \(r(B)=r(C)=p\)，控制向量和输出向量的分量都线性无关
  • \(L\)可逆
  • 充要：如果按照积分逆系统方法计算的 \(E\) 是非奇异的，则系统可以通过状态反馈+输入变换解耦

积分逆系统解耦#

积分逆系统解耦的两种形式#
频域分析（开环）#

给定被控对象\(G(s)\)，最简单地，即令补偿器\(G_{c}(s)=G^{-1}(s)\)，直接化补偿后的传递函数为单位阵，但这通常物理上不可实现（不是逆矩阵不存在）

积分逆系统解耦，即是让补偿后的传递函数 \(GG_{c}\)为积分系统

\[G(s)G_a(s) = \begin{bmatrix} \dfrac{1}{s^{\alpha_1}} & & \\ & \dfrac{1}{s^{\alpha_2}} & \\ & & \ddots \\ & & & \dfrac{1}{s^{\alpha_p}} \end{bmatrix}\]

此时，补偿器\(G_\alpha(s)\)称为原系统的\(\alpha\)阶积分逆系统，输入满足\(v_{i}=y_{i}^{\alpha_{i}}\)，第\(i\) 个分量\(y_i\)对应的\(\alpha_{i}\)

这里是直接将补偿器集成为一个独立于原系统的环节，而不是在原系统中的补偿器。给出的\(G\)已经是原系统的传递函数，状态空间里的 \(C(sI-A)^{-1}B\)

状态空间#

在状态反馈解耦中，我们通过状态反馈和输入变换直接得到积分器系统；实际上，状态反馈解耦可以看作是在原系统上串联一个积分逆系统（通过状态反馈实现）。

取恰当的\(\alpha\)，使得\(y\)的\(\alpha\)阶导数向量显含 \(\mu\)

\[y^{\alpha}=Fx+Eu\]

再引入反馈\(K=E^{-1}F,L=E^{-1}\)得

\[y^{\alpha}=Fx+E(−E^{−1}Fx+E^{−1}v)=Fx−Fx+v=v\]

具体步骤如下：

计算解耦常数#
给定状态空间表达式时#
\[αᵢ = \min \{k \mid c_{i}A^{(k-1)}B ≠ 0\}\]

第\(i\) 个分量\(y_i\)对应的\(\alpha_{i}\) ，是满足\(c_{i}A^{k-1}B \neq 0\)的最小\(k\) 值，此时对\(y_{i}\)求\(\alpha_{i}\) 阶导数，其为状态\(x\)与输入\(\mu\)的混合式子

\[y_i^{\alpha_i} = c_i A^{\alpha_i} x + c_i A^{\alpha_i - 1} B u\]

\(y_i\) 的 \(k\) 阶导中含有 \(\mu\)，那么\(\alpha_{i}\) 就是 \(k\)，

行向量不是零向量的最小阶次

给定闭环传递函数时#

传递函数矩阵有\(p\)个行向量，其中第\(i\)个可以表示为：

\[\begin{align} g_i(s) = c_i (sI - A)^{-1}B &= \frac{1}{s}c_i B + \frac{1}{s^2}c_i AB + \frac{1}{s^3}c_i A^2B + \cdots\\ &= \frac{1}{s^{\alpha_i}}c_i A^{\alpha_i - 1}B + \frac{1}{s^{\alpha_i + 1}}c_i A^{\alpha_i}B + \cdots \end{align}\]

从而，\(g_{i}(s)\) 的最小积分环节数目，即为\(\alpha_{i}\)

传递函数的幂级数展开系数就是马尔可夫参数

构造可解耦性矩阵#

根据计算的\(\alpha_{i}\)，得到

\[\mathbf{y}^{(\alpha)} = \begin{bmatrix} y_1^{(\alpha_1)} \\ \vdots \\ y_p^{(\alpha_p)} \end{bmatrix} = \begin{bmatrix} c_1 A^{(\alpha_1)} \\ \vdots \\ c_p A^{\alpha_p} \end{bmatrix} x + \begin{bmatrix} c_1 A^{\alpha_1 - 1} B \\ \vdots \\ c_p A^{\alpha_p - 1} B \end{bmatrix} u = Fx + Eu\]

如果\(E\)矩阵非奇异，则计算

\[K=E^{-1}F, \; L=E^{-1}\]

从而实现解耦（要维度匹配必定是E在前F在后）

可配置极点的解耦#

积分系统无法满足实际的动态性能需求。对第\(i\)个系统，可以配置其\(\alpha_{i}\)个极点为任意值（\(\alpha_{i}\)阶传递函数）。具体方法如下：

  • 计算\(\alpha_{i}\)，方法同上
  • 求得\(E\) 阵，同上
  • 求第\(i\)个系统的目标特征方程\(\phi_{i}(s)=0\)
  • 则\(F\)阵的第\(i\)行即为\(C_{i}\phi_{i}(A)\)

不难发现，原本的F阵满足\(F_{i}=C_{i}A^{\alpha_{i}}\)，就是特征方程\(s^{\alpha_{i}}=0\) 对应的形式

静态解耦问题#

静态解耦指的是在\(t \to \infty\)的时候，实现系统的解耦，也即在\(s \to 0\)的情况下，让传递函数矩阵近似为对角阵。该方法只适合输入信号为阶跃信号向量的情况。

仍然令 \(u=-Kx+Lv\)，

  • 必要性：

    • 检验是否有

      \[r \begin{bmatrix} A&B\\C& O \end{bmatrix}=n+p\]

    • 系统是否状态反馈可镇定

  • 给定期望的稳态输入输出关系对角阵\(D_{0}\)

  • 任求取\(K\)使得系统镇定，满足稳态条件

  • 由\(D_{0}=C(sI-(A-BK))^{-1}BL\)，代入\(s=0\)，解得

    \[L = -\left[ C(A - BK)^{-1}B \right]^{-1}D_0\]

李雅普诺夫稳定性#

  • 外部稳定性（BIBO稳定）：输入输出描述，只要求有界输入产生有界输出，但可能隐藏不稳定的内部模态（零极点相消）
  • 内部稳定性：状态空间描述，要求所有状态变量有界
  • 李雅普诺夫理论讨论的是内部稳定性

对于最小实现系统，内部稳定取零输入渐近稳定时，两者等价；但非最小实现系统可能BIBO稳定而内部不稳定

平衡状态与平衡点的稳定性#

平衡状态针对自洽系统（无输入）\(x'' + f(x, x') = 0\)

非齐次系统：\(ẋ(t) = f(x(t), u(t), t)\)方程的右边除了状态变量 x(t)，还包含输入项 u(t)、常数项或显含时间的项 t，需要求出含有\(u\)的平衡点，再用平移变换\(z(t) = x(t) - x_e\)转化为自洽系统

平衡点的稳定性是描述，受到微扰（无输入）之后，能否回到平衡点

三种稳定性

  • 李雅普诺夫稳定：
    • 幅值收敛的震荡（不远离，但不收敛回平衡点）
  • 渐进稳定
    • 渐进：收敛回平衡点
    • 这也是经典意义下的稳定
  • 不稳定
    • 远离平衡点

第一法#

间接法，判别系统矩阵\(A\)是否具有负实部特征值，也就是经典方法。非线性系统可以具备线性化，用雅可比矩阵

\[A \sim \begin{bmatrix} \nabla f_{1}\\ \nabla f_{2}\\ \nabla f_{3}\\ \end{bmatrix}\]

对平衡点附近连续可微的非线性系统，其线性化判据如下

  • 线性化系统渐进稳定 \(\implies\) 原系统稳定
  • 线性化系统有正实部特征值而不稳定 \(\implies\) 原系统不稳定
  • 线性化系统李雅普诺夫意义稳定（纯虚数特征值，经典里的临界稳定），方法失效

局部线性化只能得出局部稳定性结论

第二法#

都是充分条件

稳定的范围 与 稳定性，是两回事。稳定性看负定/半负定/正定，范围看是全局都这样，还是局部

全局判定#

渐进稳定基本定理

  • \(V(x,t)\)正定
  • \(\dot{V}(x,t)\)负定

渐进稳定第二定理

  • \(V(x,t)\)正定
  • \(\dot{V}(x,t)\)半负定，且\(x \neq 0\)时，\(\dot{V}(x,t) \not\equiv 0\)

大范围渐进稳定(能量发散)

  • \(V(x,t)\)正定
  • \(\dot{V}(x,t)\)负定 或 \(\dot{V}(x,t)\)半负定，且\(x \neq 0\)时，\(\dot{V}(x,t) \not\equiv 0\)
  • \(\lim_{|x| \rightarrow \infty}V(x,t)=\infty\) （保证可以扩展到整个状态空间）

李雅普诺夫稳定

  • \(V(x,t)\)正定
  • \(\dot{V}(x,t)\)半负定

不稳定判定

  • \(V(x,t)\)正定
  • \(\dot{V}(x,t)\)正定 或 \(\dot{V}(x,t)\)半正定，且\(x \neq 0\)时，\(\dot{V}(x,t) \not\equiv 0\)
局部判定#

如果负定条件在局部成立，那系统具备局部渐进稳定。同理，局部半负定，则局部稳定。

能量函数在一定范围内负定，超出后正定确实可以被视为局部渐近稳定。这意味着当干扰不大（即初始状态在吸引域内）时，系统肯定会回到平衡点。

线性定常系统#

渐进稳定的充要条件：

\[\exists P，P对称且正定，使得A^{T}P^{T}+PA=-E\]
\[离散情况：G^TPG-P=-E\]

这个也叫李雅普诺夫方程

推导：

  • 取\(V=X^{T}PX\)，求导为\(\dot{X}^{T}PX+X^{T}P \dot{X} = X^{T}A^{T}PX +X^{T}PAX\)，
  • 离散情况取\(V(k)=X^{T}(k)PX(k)\)，做差分\(V(k+1)-V(k)=X^{T}(k+1)PX(k+1)- X^{T}(k)PX(k)=X^{T}(k)G^TPGX(k)-X^{T}(k)PX(k)\)

应用方法，设\(P\)，求解线性方程组，再验证\(P\)是否正定

克拉索夫斯基法#

充分性，一种构造思路

对\(\dot{x}=f(x)\)，构造\(V(x)=f^{T}(x)f(x)\)，则\(\dot{V}(x)=f^{T}(x)(J^{T}(x)+J(x))f(x)\)

在大范围上验证\(J^{T}(x)+J(x)\)的负定性是否成立。注意如果\(J(x)\)不满足对角线元素都是负数，就不用验证了

对比：局部线性化，是在平衡点检验特殊的\(J(x_{e})\)是否负实部，而且\(A^{T}+A\)负定是比\(A\)的特征值都具有负实部更强的条件
